# API message examples

Ejemplos sintéticos del contrato JSON común. No contienen credenciales ni datos reales.

- [Petición de ejemplo](api-request.example.json)
- [Respuesta exitosa](api-response-success.example.json)
- [Respuesta de error](api-response-error.example.json)

Los payloads `data` son específicos por endpoint y se validarán con los esquemas dedicados. No enviar secretos, tokens, contraseñas, códigos MFA ni cuerpos sensibles completos a logs.
